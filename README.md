# Шаблон плагина Koda Desktop

Стартовый репозиторий для своего плагина. Внутри панель рядом с чатом,
инструмент агента `echo` и автоматическая сборка релиза.

## Плагин за 10 минут

1. Нажмите **Use this template** на GitHub и склонируйте свой репозиторий.
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Откройте `koda-plugin.json` и поменяйте:
   - `id` на свой, в обратной записи домена: `dev.<ваш-ник>.<плагин>`. После публикации его менять нельзя;
   - `name`, `description`, `publisher`.
4. Запустите разработку:
   ```bash
   npm run dev
   ```
5. Соберите архив и установите его в Koda Desktop: «Маркетплейс → Установленные → Установить из файла».
   ```bash
   npm run pack
   ```

## Что где лежит

| Файл | Зачем |
| --- | --- |
| `koda-plugin.json` | Манифест: id, версия, разрешения, панели, инструменты агента |
| `main.js` | Главная часть. Работает в песочнице, всё делает через `ctx` |
| `ui/` | Интерфейс панели. Без сети, связь с `main.js` через `window.kodaPlugin` |
| `icon.svg` | Иконка плагина |
| `.github/workflows/release.yml` | Сборка релиза по тегу |

Полный справочник по `ctx`, разрешениям и дизайну есть в README пакета `@kodadev/desktop-plugin-sdk`.

## Разрешения

Просите только то, что действительно нужно. Пользователь видит список при установке,
а каждое новое разрешение в обновлении снова требует его согласия.

## Выпуск версии

1. Поднимите `version` в `koda-plugin.json`.
2. Создайте тег с той же версией и отправьте его:
   ```bash
   git tag v0.2.0 && git push --tags
   ```
3. GitHub Actions соберёт `.kodaplugin` и приложит его к релизу вместе с `SHA256SUMS`.
4. Чтобы плагин появился в каталоге Koda, откройте PR в `plugin-registry`
   со ссылкой на архив и его SHA-256.
